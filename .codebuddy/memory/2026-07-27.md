## 基金模块二次优化：isUpdated 盈亏判定 + ETF/货基 兼容（已实施）
- 背景：用户要求保留盘中估值，并优化 `isUpdated` 盈亏判断、对 ETF/货基 做兼容。
- 新浪 `fu_` 字段实测（000001）：f[0]=名称 f[1]=估值时间(仅时分秒) f[2]=估算净值 f[3]=昨日净值 f[6]=估算涨跌幅% f[7]=净值日期(盘中为今日)。
- 改动（同文件 `src/explorer/fundService.ts`）：
  1. `getData` 的 `isUpdated` 由失效的日期比对改为 `!FundService.isMarketOpen()`（中国时区，周一至周五 9:30-11:30、13:00-15:00 为交易时段）→ 盘中显示实时盈亏、闭市显示结算盈亏。
  2. 新增 `isMarketOpen()` / `chinaDateString()` 两个静态辅助方法（按 UTC 偏移推算中国时区）。
  3. 新增 `mapFuData()`（fu_ 映射，gztime 补全为 `jzrq + 空格 + 时分秒`）、`mapStockData()`（股票行情映射）、`qryStockQuote()`（sh/sz 兜底）。
  4. `qryFundInfo`：`fu_` 无数据时回退 `qryStockQuote`（兼容场内货基ETF 511880 等）；空值字段补 `--`。
- 验证（node 实测真实接口）：

  - 场外货基 000198（余额宝）：`fu_` 与 sh/sz 均无数据 → 暂无数据（无免费实时源，迁移前同样不可用，属已知局限）。
  - `isUpdated` 在午休(11:34)正确判为闭市；交易时段内应为盘中实时盈亏。
