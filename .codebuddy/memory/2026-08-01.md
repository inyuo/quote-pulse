## 快讯界面空白 BUG 修复（已实施 + 打包）
- 现象：快讯输出面板与侧边栏"快讯"视图均空白。
- **根因**：选股宝接口 `https://baoer-api.xuangubao.cn/api/v6/message/newsflash` 在未带 `Referer` 头时，虽返回 `code:20000` 但 `data.messages` 为 `undefined`（实测确认），导致两处 `Array.isArray(messages)` 校验失败返回空。原代码 `xuangubaoProvider.ts` 与 `XuanGuBaoFLushServices.ts` 的 axios 请求都**漏了 headers/Referer**。
- 修复：上述两处 axios.get 均补 `headers: { 'User-Agent':'Mozilla/5.0', Referer:'https://xuangubao.cn/' }`，带 Referer 实测返回 5 条正常。
- 附带：将 `investment-monitor.flash-news` 默认值由 `false` 改为 `true`，使输出面板+状态栏 ⚡️ 开箱即用（否则该开关关时面板/状态栏根本不创建，也是"空白"的常见原因）。
- 验证：`yarn compile` + `npx vsce package` 成功 → `investment-monitor-3.20.6.vsix`。read_lints 0 报错。

## 点击快讯跳转 Webview 空白 BUG 修复（已实施 + 打包）
- 现象：侧边栏点快讯文字 → `investment-monitor.xuangubaoNews` → `XuanGuBaoNewsView.show()` 打开的 Webview 整页空白。
- **根因**：`XuanGuBaoNewsView.getHtml()` 注入 `window.initialRoute='/data-center/xuangubao-news'`，但前端 `template-packages/leek-center/src/router-config.ts` 未注册该路由（只有 `/data-center`、`/my-stocks`、`/news`），React Router 匹配失败 → 整页空白。后端 `getNewsData/newsData` 数据通道本身正常。
- 修复（改前端，需重新 build）：
  1. `router-config.ts`：新增 `path:'/data-center/xuangubao-news'` → `XuangubaoNews`（`@/view/data-center/xuangubao-news`）。
  2. `App.tsx`：`hideLayoutPaths` 加入 `/data-center/xuangubao-news`（隐藏 Header/Footer 布局）。
  3. 重新 `cd template-packages/leek-center && yarn build`（输出到 template/leek-center/build），再 `yarn compile` + `npx vsce package`。
- 验证：leek-center build 成功（12.7s），`yarn compile` + `npx vsce package` 成功 → `investment-monitor-3.20.6.vsix`（3373 文件）。read_lints 0 报错。
- 注意：`yarn compile` 的 postcompile 会调 leek-center build，但本仓库用 `yarn compile` 时若未触发前端 build，需手动 build 前端（已手动跑）。今后改 leek-center 源码后必须重新 `yarn build` 再打包。
